# Artifact index

- `REPORT.md`: methods, results, architecture, and limitations.
- `summary.json`: compact accepted machine result.
- `adaptive_oracle.png`: elastic throughput relative to measured fixed oracle.
- `adaptive_trajectories.png`: representative Worker control trajectories and
  memory limit.
- `controller_ingest.png`: Controller object-ingest connection sweep.
- `architecture.png`: final Scheduler/Worker/Controller boundary.
- `render_results.py`: deterministic figure generator.
- `raw/`: compact final evidence only; see `raw/README.md`.
- `SHA256SUMS`: integrity manifest for every retained artifact.
